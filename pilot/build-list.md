# Build list

*The team's own list of what it said it would build, and whether each thing now exists. This is the
pilot's primary measure: countable, behavioural, and legible to someone outside the team.*

Status is one of `named`, `in progress`, `exists`, `dropped`. `exists` needs evidence — a path in this
repository or a link — and a dropped item keeps its row and says why, because a considered no is a
result too. `pilot/measure.sh` counts the rows and the ones marked `exists`.
