# Projects

The register: one row per project, linking its folder. Each project's `README.md` is canonical, and
where a row disagrees with one, the README wins. `/projects:new` adds a row under Active,
`/projects:hold` moves one to Paused, `/projects:pickup` moves it back, and `/projects:close` moves it
to Done, where the folder link points into `_done/`.
