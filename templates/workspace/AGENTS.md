# How this workspace is read

This workspace's standards are in two files, read in this order: `kit/CLAUDE.kit.md`, the kit's, and
`CLAUDE.md`, this team's, which wins where they differ. A tool that follows `@` imports has the first
already; a tool that does not reads both. Projects live in `projects/`, one folder each, `README.md` first.
