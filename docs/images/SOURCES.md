# Image sources

Every binary image in `docs/images/` has a row here saying how it was made. The kit's path check
(`scripts/check-paths.sh`, rule R1) lets a `.png` in this folder through only when its file name is in
the first column and the second column says how it was made; any other binary file is refused. Text
images such as `.svg` need no row.
